## *Задача 3.2*
Для запуска выполнить 
```
./build_and_run
```
После выполнения программы в папке `results` будут записаны файлы `.txt` для трех функций: `pow`, `sin`, `sqrt`.

Так же вывод значений точности в терминал. Пример:
```
Файл results/pow.txt, точность = 0.9936
Файл results/sin.txt, точность = 1
Файл results/sqrt.txt, точность = 1
```
