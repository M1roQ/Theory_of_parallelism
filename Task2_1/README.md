## *Задача 2.1*
Для запуска выполнить 
```
./build_and_run
```
После выполнения программы в папке `results` будут записаны файлы `.csv` и `.png`.
`.csv` - таблица, содержащая время и ускорение по разному числу потоков.
`.png` - графики ускорения для матриц 20000x20000 и 40000x40000. Также изображено линейное ускорение.
